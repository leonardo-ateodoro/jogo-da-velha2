# ❌⭕ Jogo da Velha (Tic-Tac-Toe) - Versão Refatorada e Evoluída

Este projeto consiste na refatoração e evolução do tutorial oficial do Jogo da Velha (Tic-Tac-Toe) do React. O objetivo principal é transformar o exemplo básico em uma aplicação de nível profissional, adotando uma arquitetura moderna, estilização modular, boas práticas de Clean Code e acessibilidade.

---

## 🎯 Objetivo do Projeto

- **Refatoração:** Migrar o código original em arquivo único para uma estrutura de componentes isolados com responsabilidades bem definidas.
- **Design System:** Implementar estilização profissional utilizando CSS Modules, variáveis CSS e metodologia BEM (Block, Element, Modifier).
- **Acessibilidade & Usabilidade:** Garantir o uso de HTML semântico, suporte a leitores de tela, foco acessível via teclado e layout responsivo.
- **Qualidade de Código:** Aplicar conceitos de imutabilidade no estado do React, tratamento de exceções e padronização rigorosa de nomenclaturas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação acessível das páginas e componentes.
- **CSS3 / CSS Modules:** Estilização escopada por componente com variáveis globais e convenção BEM.
- **JavaScript (ES6+):** Lógica da aplicação e manipulação de estado.
- **React (v18+):** Biblioteca principal para renderização de interface baseada em componentes.
- **Vite:** Ferramenta de build rápida e servidor de desenvolvimento local.
- **Bootstrap:** Suporte para utilitários visuais e estruturas de layout (quando necessário).
